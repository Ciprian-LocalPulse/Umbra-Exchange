# Support Umbra Exchange

**Umbra Exchange** is independent, self-funded, public-interest research focused on building privacy-preserving threat-intelligence infrastructure using zero-knowledge proofs, anonymous contributor credentials, private set intersection, and interoperable STIX 2.1 / MISP workflows.

Funding directly determines how much time can go into protocol specification, cryptographic implementation, testing, security research, and eventually independent security audits — the parts of this project that are slow, technically demanding, and essential for a system intended to support trustworthy threat-intelligence exchange.

## What Contributions Fund

Contributions directly support the continued research and development of Umbra Exchange, including:

* Development and refinement of the zero-knowledge proof-of-observation system
* Implementation of Merkle-inclusion proofs, Poseidon hashing, credential gadgets, and nullifiers
* Development and testing of the anonymous contributor tiering and reputation mechanisms
* Research and implementation of private set intersection (PSI) for privacy-preserving blocklist checks
* STIX 2.1 and MISP interoperability
* Cryptographic testing, benchmarking, threat modeling, and protocol documentation
* CI infrastructure, development tooling, documentation, and research infrastructure
* Independent third-party security and cryptographic audits as the project matures
* Continued protocol development and implementation
* Eventually, compensating dedicated maintainers for specific subsystems

## Funding Transparency

Umbra Exchange is an independently developed research project.

Financial support is intended to support the project's technical development along the following path:

**Research → Protocol Specification → Cryptographic Implementation → Testing → Security Auditing → Maintenance**

Contributions do not purchase ownership of the project, control over the protocol specification, preferential treatment, access to private threat intelligence, or influence over security decisions.

The project's technical direction remains independent.
